# 权重归一化模型重做方案（WP-7.3）

**版本**：v1.0（方案）
**日期**：2026-08-31
**归属**：H1 可信化 WP-7 阶段 3
**状态**：方案文档（H3 实施前置，本阶段仅出方案不实施）
**目标**：废除散落权重口径，引入"激活子集全局归一化"统一模型。

## 一、问题：现有"4 维基座 + 增强折叠"模型的缺陷

### 1.1 现状（arch_report.py）

```
结构质量(基座) × base_w + 各增强 × 固定权重
base_map = {1: 0.85, 2: 0.70, 3: 0.60, 4: 0.55}   # 按激活增强数分档
enh: ml=0.15, tpl=0.15, nvr=0.10, sp=0.15
if 激活数>=3 且 权重和>1: scale = 1/real_w （等比缩放）
```

### 1.2 缺陷

| 缺陷 | 说明 |
|:-----|:-----|
| **非单调** | 激活增强越多，基座权重越低（0.85→0.55），但基座结构质量是主维，被任意削弱 |
| **口径散落** | 权重数值散落 5 处：arch_report.py / 4 skill / AGENTS.md / 指南，无单一事实源 |
| **语义混乱** | "增强权重 15%" 与基座 30% 无法直接比较（增强内部还需再分解）|
| **不可扩展** | 新增引擎（H2 安全/可观测性）需改 base_map 与增强权重 |

## 二、方案：激活子集全局归一化

### 2.1 核心公理

> **任一项目激活的维度权重之和 = 1**

不区分"基座"与"增强"，所有维度（含结构/设计/文档/演进 + 多语言/模板/数值/求解器）统一为**项目激活子集**，内部全局归一化。

### 2.2 模型定义

```
全局候选维度集 D = {d1, d2, ..., d8}（元模型注册表定义）
项目激活子集 A ⊆ D（由引擎检测确定：is_single/has_cpp/has_numerical/has_multiphysics）
归一化：对 d ∈ A，w_d' = w_d / Σ_{d∈A} w_d   （保证 Σ w_d' = 1）
```

### 2.3 示例

| 激活维度 | 原始权重 | 归一化权重 |
|:---------|:--------:|:----------:|
| 标准 4 维（恒激活）| 0.30/0.25/0.20/0.25 | 同左（和=1.0）|
| + 数值 | 0.10 | 0.30/0.227/0.182/0.227/0.091（×1/1.1）|
| + 模板 | 0.10+0.15 | 0.30/0.25/0.20/0.25/0.15/0.10（×1/1.25）|
| + 模板 + 数值 | 0.10+0.15+0.10 | ×1/1.35 |

**性质**：
- 单调性：基座权重随激活维度增多而**平滑下降**（不再分档跳跃）
- 恒等式：任意激活子集和=1
- 可比较：所有维度权重同一尺度

### 2.4 与现有增强权重的映射

| 增强 | 现有固定权重 | 新模型（作为候选维度权重）|
|:-----|:----------:|:----------:|
| 多语言 | 0.15 | 0.15 |
| 模板 | 0.15 | 0.15 |
| 数值 | 0.10 | 0.10 |
| 求解器 | 0.15 | 0.15 |

候选集权重保留现有值，仅归一化逻辑改为全局子集。
