- **ACL CAD 计数基线**：FreeCAD STEPPlugin、SALOME import/export 目录直连计数（核对"偏高"是否真实耦合）。
- **语义级语料基线**：OCCT 40 处 BRepFeat/BRepFill/CheckAndLoad；deal.II 隐式实例化计数。
- **运行时检测前置**（决策 3）：确认 CI 可构建 OCCT 内核，打通 `--build-dir` 动态任务通道。

- 验收：数据可复现，供各 WP 对比。

### WP-1 激活子集全局归一化（A1，3 周，最高优先）— 评分语义
依据 `权重归一化模型重做方案.md §四` + 决策 1/2/5：
1. registry 补全各引擎内部维度权重（多语言 6 维 / 模板 6 维 / 数值 6 维 / 物理场 4 维 / GCS 4 维 / ACL 4 维）。
2. 新增 `calc_activate_subset(project)` 返回激活维度集。
3. `arch_report.py` 改用注册表 + 全局归一化，**删除** `base_map` / `enh_raw` / 等比缩放（现 `arch_report.py:134-143`）。
4. skill 权重表改为引用注册表（或注释指向事实源）；AGENTS.md / 指南同步。
5. **替代过渡口径 8b**（`arch_report.py:173-176` 的 `subset_scoring` 标注），激活子集评分成为正式语义。
6. **决策 1**：增强内部维度归一化——增强总分作为激活子集内的一个"超级维度"，内部维度权重保持。
7. **决策 2**：求解器"按产品类型调权"作为 profile 维度权重覆盖纳入模型。
8. **决策 5**：归一化改变语义 → **全部快照按语义变更重设基线并留档迁移记录**（不只做 <5% 偏移校验）。
- 验收：单一 schema 事实源；激活子集权重和 = 1；快照新基线重设 + 迁移记录归档。

### WP-3 维度⑥ 并行/异构计算架构（HPC/GPU）全链路（E3 + Roadmap，6 周）

- 规则族 4 类：① 后端接口一致性（CPU/GPU 数值一致、异构调用点）② MPI 域分解与 halo 交换 ③ 负载均衡与进程拓扑 ④ 混合并行（MPI×OpenMP）冲突检测。

- 案例：OpenFOAM（MPI 域分解）、PETSc/deal.II（并行后端）、SU2。
- 验收：12 规则每条 ≥1 用例；回归 ≥5 项目；三方一致 PASS；规则可行性分级 + KNOWN_HOLES 通道（学 H2 先例）。
