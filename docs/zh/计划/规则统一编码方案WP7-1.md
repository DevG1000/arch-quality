**版本**：v1.0
**日期**：2026-08-31
**归属**：H1 可信化 WP-7 阶段 1（标准元模型 v1.0 草案前置）
**状态**：草案（待 WP-7.2 schema 校验）

---

## 一、目标

消除规则编号的三类问题，为元模型提供**唯一、连续、无歧义**的规则编码：

| 问题 | 现状 | 后果 |
|:-----|:-----|:-----|
| 模板规则占用 MLR 命名空间 | MLR-013~024 与多语言 MLR-001~012 同前缀 | 报告/工具中 MLR-0xx 歧义，无法区分引擎归属 |
| 编号断层 | NVR-009（指南 1.3 移出主规则表）、MPR-011（合并入 MPR-005）| 无法按 001~012 连续建模，引用落空 |
| 豁免字段无统一 schema | 5 种注解各带自定义字段 | 无法机器校验存在则必填 |

### 2.3 空洞补齐

#### NVR-009 确认就绪度检查（重新启用）

- **背景**：指南 1.3 版移出主规则表至附录 A；案例集 §12 有完整定义
- **定义**：按 ASME V&V 20 框架的确认流程就绪度检查（六要素：验证点选择标准/实验数据及不确定度/比较方法/不确定度聚合/确认不确定度/确认报告）
- **output_level**：INFO（独立附加项，不阻塞）
- **severity**：LOW
- **豁免**：无

#### MPR-011 跨场时间同步协调（新启用）

- **背景**：原 MPR-011 合并入 MPR-005 后编号空洞；skill §2.4 子项 5-6（时间同步机制规范性 + 时间步协调策略合理性）当前无单列规则
- **定义**：跨物理场时间步同步/协调策略缺失或不当（统一步长/子循环/异步无管理）
- **output_level**：WARNING
- **severity**：MEDIUM
- **豁免**：无

## 三、迁移顺序

重编号涉及 4 类引用面，按以下顺序迁移（兼容期双 ID 并行）：

| 序 | 引用面 | 文件 | 动作 |
|:--:|:-------|:-----|:-----|
| 1 | 定义源 | skills/template-metaprogramming.md | 规则表 MLR-013~024 → TPL-001~012；豁免注解说明同步 |
| 2 | 工具实现 | rch_metrics_template.py | 规则 ID 常量重命名；豁免协调逻辑同步 |
| 3 | 报告硬编码 | rch_report.py:264-265 | MLR-013/015 交叉关注 → TPL-001/003 |
| 4 | 验证资产 | 模板验证案例库（60 处引用）| MLR-013~024 → TPL-001~012 |
| 5 | 回归基线 | 	ests/regression/snapshots/ 模板相关 | 重生成 |

## 四、豁免字段建模

**原则**：豁免注解字段为**可选字段，存在则必填**（缺任一必填字段 → 豁免无效，output_level 不降级）。

### 4.1 统一 schema（草案）

| 字段 | 类型 | 必填 | 说明 |
|:-----|:----:|:----:|:-----|
| nnotation | string | ✅ | 注解名（@xxx）|
| 
ule | string | ✅ | 适用规则 ID（如 TPL-002）|
| 
eason | string | ✅ | 豁免理由 |
| ields | object | ✅ | 规则特有必填字段 |
| ields.* | any | ✅ | 存在则必填（由规则 schema 定义）|
| ile | string | 否 | 声明文件（工具填充）|
| line | int | 否 | 声明行号（工具填充）|

### 4.2 各引擎豁免注解字段清单

| 注解 | 适用规则 | 必填字段 |
|:-----|:---------|:---------|
| @template_specialization_required | TPL-002（原 MLR-014）| reason |
| @allow_binary_bloat | TPL-005（原 MLR-017）| reason, performance_gain, compile_time_increase, benchmark_script, threshold |
| @reserved_for_future_extension | TPL-006（原 MLR-018）| reason, types |
| @mms_exempt | NVR-005 | reason, verification_method, test_script, threshold |
| @order_deviation_allowed | NVR-006 | reason, expected_order, observed_order, benchmark_case |
| @custom_data_structure | MPR-010 | reason, alternative_method, test_script, threshold |
| @coherence_approved | MPR-004 | reason, architecture_type, verification_case |

### 4.3 字段校验规则

1. 注解存在但字段缺失 → 输出 [豁免语法缺失]，output_level 维持原级别
2. 字段值为空串 → 视为缺失
3. 豁免仅在同文件内生效，跨文件不作用
4. 同一规则多处豁免 → 分别校验，任一失败则该处豁免无效
