## 一、目标与范围

**主目标**：存量能力完整、可信、可发布。"可信"含两层——工程可信（可复现、可门禁）+ 测量可信（评估结论本身无系统性误判）。

| 层 | 交付要点 | 验收 KPI（v3） |
|---|---|---|
| 产品层 | 测试覆盖度升级 / 规则回归补全 / 边界裁决矩阵 / 性能 / 报告矩阵 / 门禁与 CI / 试点 | 规则覆盖矩阵 100%；FreeCAD 全量 <10 分钟（P90）；**核心规则假阳性率 ≤10%** |
| 内容层 | 标准元模型 v1.0 草案 + 规则统一编码方案 + 权重归一化模型重做方案 | 草案 + 编码方案 + 映射表 + validator（最小集）通过 |
| 能力层 | 一致性检查器重构并入 CI（先自动后阻塞） | 5 维度全 PASS |

## 四、工作包分解

### WP-0 基线实测（P0 前置，1 周）
- 性能基线：FreeCAD `src/` 全量（12417 文件）耗时实测；5 个回归项目各自耗时；声明机型/冷热缓存/分位数（P50/P90）
- **假阳性基线**：BRL-CAD + FreeCAD 上按规则人工抽检，记录各规则 触发数/确证数/疑似假阳性数（为 KPI5 提供基线）
- 回归基线盘点：绝对路径清单、项目体积、快照依赖的工具版本
- 产出：`docs/zh/计划/H1基线实测报告.md`
- 验收：KPI 数据可复现、可作为 WP-3 对比基准
