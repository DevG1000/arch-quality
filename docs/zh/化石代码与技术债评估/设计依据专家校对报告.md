1. SQALE 标为"方法/工具"，非 ISO 标准；
2. 补 CK 1994、CISQ/ISO 5055:2021、Cunningham 1992、Fowler 1999/2018 出处；
3. D1 修改标准基线的快照影响与校验流程；
4. FOS-006 精确描述标准正则范围（仅 `/* ... if/for/class/return ... */`）；
5. FOS-001 固定格式判定依据（列/扩展名/编译选项）；
6. FOS-002 剥离注释/字符串后再判 `register`；
7. Code_Aster 本地样本仅 2 个 `.f`，阶段 B 固定 ref 复核；
8. OpenFOAM 角色改为"债务标记样本"或补遗留 API 锚点。
