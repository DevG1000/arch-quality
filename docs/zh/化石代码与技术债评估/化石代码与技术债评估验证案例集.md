## 一、A 类：可复现开源项目案例

> **口径**：本维度是“风险检测”，A 类中“**形态阳性**”指**应触发**（含化石形态），“**健康阴性**”指**不应触发/低触发**。  
> A 类通过本地 checkout 或 `projects.yaml` 固定 ref；预期结果为**手工语义预期**，供阶段 C 对照。真实开源健康阴性样本待阶段 C 固定，本版由 §四 N-1 合成基准承担。

### A-1：Code_Aster — FOS-001 形态阳性

- **获取**：`D:\OPENSOURCE\code_aster`（本地 checkout；`projects.yaml` 固定 ref 待补）
- **关键锚点**：`astest/umat001a.f:87` `IMPLICIT REAL*8 (A-H,O-Z)`；`astest/umat002a.f:86`
- **形态分析**：
  - 固定格式（`C` 注释、6 空格缩进）；
  - `IMPLICIT REAL*8` 隐式类型；
  - 本地 checkout 仅 2 个 `.f`，**不代表全仓**；阶段 C 以固定 ref 复核。
- **预期结果（v0.2）**：
  - FOS-001 → **触发**（40 分）；
  - FOS-002 → 待阶段 C 实测（本地未逐一核验 `auto_ptr`，不作“不触发”断言）；
  - FOS-004/007/011/012 → 候选（引用图/克隆/成本/年龄，需阶段 C 实测）；
  - 不据此给全仓分数结论。

### A-2：BRL-CAD — FOS-001/002 形态阳性

- **获取**：`D:\OPENSOURCE\brl-cad`（本地 checkout；固定 ref 待补）
- **关键锚点**：
  - `src/conv/patch/rpatch.f`、`misc/fortran_example.f`：自有固定格式 Fortran（**无 `COMMON`**）；
  - `src/librt/vshoot.c:49` `register int i;`。
- **形态分析**：
  - 自有 Fortran 是固定格式（FOS-001 参照）；
  - `register` 是旧 C 关键字（FOS-002 阳性）；
  - `COMMON` 主要在 `third_party/liblbfgs`，**排除**，不作 FOS-001 阳性。
- **预期结果（v0.2）**：
  - FOS-001 → **触发**（固定格式；无 `COMMON` 不等于不触发）；
  - FOS-002 → **触发**（`register`）；
  - FOS-010 → 低/候选（需实测）；
  - 第三方 `COMMON` 不计。

### A-3：OpenFOAM — FOS-010 形态阳性 + FOS-002 阴性

- **获取**：`D:\OPENSOURCE\OpenFOAM-v2512`（本地 checkout）
- **关键锚点**：
  - `src/conversion/ccm/writer/ccmWriterSolution.C:428` `// HACK`/`// FIXME`；
  - `src/conversion/ccm/reader/ccmReaderSolution.C:353` `#define SOLID_STRESS_HACK`；
  - `src` 中 `auto_ptr` **无命中**。
- **形态分析**：
  - 债务标记（HACK/FIXME）→ FOS-010 阳性；
  - `auto_ptr` 无命中 → **FOS-002 阴性**（不能把注释/文档计数当正样本）；
  - 无 F77 固定格式 → FOS-001 阴性。
- **预期结果（v0.2）**：
  - FOS-010 → **触发**（密度需阶段 C 实测，局部锚点仅证明信号存在）；
  - FOS-002 → **不触发**；
  - FOS-001 → **不触发**（无 F77）。

> **A 类覆盖说明**：A-1/A-2/A-3 为“形态阳性”可复现样本；**整仓健康阴性**由 §四 N-1 合成基准承担。不得把 A 类阳性当“健康样本”或反之。

## 三、C 类：Validation 案例（6 要素）

### C-1：某 CAE 平台 F77 模块现代化（首期）

| 要素 | 内容 |
|:--|:--|
| **前情背景** | 某 CAE 平台含 20 年历史 F77 求解器，团队 15 人；计划升级编译器并支持新平台 |
| **工具输出（示意）** | 指南 v0.2 输出：FOS-001（固定格式/`COMMON`，WARNING，40）、FOS-002（`auto_ptr`，WARNING，40）、FOS-006（成块注释，INFO，20）、FOS-010（TODO 密度 7/KLOC，INFO，25）；维度⑦ 综合分 **64.5**（“需改进”）；门禁 WARN |
| **用户行为** | 架构师先处理 FOS-001：`COMMON` 改 `MODULE` 变量、`IMPLICIT NONE`；对 ABI 兼容接口加 `@fossil_legacy_ok`；FOS-002 排入下一迭代 |
| **决策过程** | 以“升级阻塞优先”排序：FOS-001（编译/平台）> FOS-002（标准升级）> FOS-010（债务）；保留 1 个旧接口文件并登记豁免 |
| **结果与价值** | 复评：FOS-001 清零、FOS-010 降至 4/KLOC（清零）、FOS-006 保留、FOS-002 保留（候选）；综合分 64.5 → **84.0**（“良好”）；编译器升级通过 |
| **经验提炼** | 先清“固定格式/`COMMON`”再清“废弃 API”；ABI 兼容用 `@fossil_legacy_ok` 显式登记，不静音 |

> 案例-指南版本绑定：本案例预期基于指南 **v0.2**；指南升级需同步更新。  
> **说明**：C-1 为**示例场景**，分数（64.5→84.0）与告警为**示意数据**，非某真实项目实测。

## 四、合成正负例（12 规则，各 1 正 + 1 负）

> 合成代码为**最小示意**；引用真实 API 处须与源码一致（阶段 C 校准可编译性）。伪代码已标注。

### 4.1 FOS-001 F77 固定格式/`COMMON`/`IMPLICIT`

**正例（触发）**：
```fortran
      PROGRAM LEGACY
      IMPLICIT REAL*8 (A-H,O-Z)
      COMMON /BLK/ X
      X = 1.0D0
      END
```
**负例（不触发）**：
```fortran
program modern
  implicit none
  real(8) :: x
  x = 1.0d0
end program modern
```

### 4.2 FOS-002 废弃 C++ API

**正例（触发）**：
```cpp
#include <memory>
void f() {
  std::auto_ptr<int> p(new int(1)); // C++17 removed
  register int i = 0;               // C++17 removed
}
void g() throw(int);                // throw(type): C++17 removed
```
**负例（不触发）**：
```cpp
#include <memory>
void f() { auto p = std::make_unique<int>(1); }
void g() noexcept;
```

### 4.3 FOS-003 K&R C/非标准方言

**正例（触发）**：
```c
int add(a, b)
int a;
int b;
{
    return a + b;
}
```
**负例（不触发）**：
```c
int add(int a, int b) {
    return a + b;
}
```

### 4.4 FOS-004 未引用函数/变量/文件

**正例（触发）**：
```c
static void legacy_init(void) { /* no caller in repo */ }
```
**负例（不触发）**：
```c
static void legacy_init(void) { /* ... */ }
int main(void) { legacy_init(); return 0; }
```

### 4.5 FOS-005 不可达分支

**正例（触发）**：
```c
#if 0
old_impl();
#endif
return;
unreachable();
```
**负例（不触发）**：
```c
if (mode == LEGACY) { legacy_impl(); }
return;
```

### 4.6 FOS-006 成块注释代码

**正例（触发；>10 行 WARNING，≤10 行 INFO）**：
```c
/*
if (mode == LEGACY) {
    legacy_init();
    legacy_step();
    legacy_finalize();
}
*/
```
> 说明：上例为 7 行 → INFO（仍计 20 分）；扩到 12 行 → WARNING。检测按行数分级。

**负例（不触发）**：
```c
/* Compute flux for the legacy boundary. */
```

### 4.7 FOS-007 函数/文件级克隆

**正例（触发）**：
```cpp
// a.cpp
double flux_a(double u, double v) { return u * v + 0.5 * (u - v); }
// b.cpp（复制粘贴，仅函数名不同）
double flux_b(double u, double v) { return u * v + 0.5 * (u - v); }
```
**负例（不触发）**：
```cpp
// common.hpp
inline double flux(double u, double v) { return u * v + 0.5 * (u - v); }
```

### 4.8 FOS-008 跨文件重复常量

**正例（触发）**：
```cpp
// a.cpp
const double K = 0.85;
// b.cpp
const double K = 0.85;   // 重复常量（≥2 文件/≥3 处）
// c.cpp
const double K = 0.85;
```
**负例（不触发）**：
```cpp
// constants.hpp
inline constexpr double K = 0.85;   // 单点定义
```

### 4.9 FOS-009 同一算法多份实现

**正例（触发；伪代码）**：
```cpp
// rk4_a.cpp（伪代码）
void rk4_a(...) { /* RK4 步骤 A */ }
// rk4_b.cpp（伪代码）
void rk4_b(...) { /* RK4 步骤 B，与 A 等价 */ }
```
**负例（不触发）**：
```cpp
// integrator.hpp
template<class F> void rk4(F f, ...) { /* 一份实现 */ }
```

### 4.10 FOS-010 债务标记密度

**正例（触发）**：
```cpp
// TODO: replace legacy solver
// FIXME: temp workaround
// HACK: skip validation
// XXX: unsafe cast
// ... 示意：4 条 / 0.5 KLOC = 8/KLOC（>5/KLOC）
```
**负例（不触发）**：
```cpp
// TODO: none (density 0/KLOC)
int main(void) { return 0; }
```

### 4.11 FOS-011 SQALE 修复成本比率

**正例（触发，示意数据）**：

| 项 | 值 |
|:--|:--|
| 违规数 | 120 |
| 代理成本 | 120 × 2h = 240h |
| 规模 | 20 KLOC |
| 比率 | 12h/KLOC（超阈值） |

**负例（不触发，示意数据）**：

| 项 | 值 |
|:--|:--|
| 违规数 | 10 |
| 代理成本 | 20h |
| 规模 | 20 KLOC |
| 比率 | 1h/KLOC |

### 4.12 FOS-012 遗留模块无测试

**正例（触发）**：
```text
src/legacy/
  solver.f90        # git 首次提交 2010；无 test/ 目录、无断言
```
**负例（不触发）**：
```text
src/legacy/
  solver.f90        # git 首次提交 2010
  tests/test_solver.f90   # 有回归测试/断言
```

### N-1 健康阴性基准（全规则不触发）

```cpp
// C++17；无废弃 API；无 TODO；有 tests/
#include <memory>
int main() { auto p = std::make_unique<int>(1); return *p; }
```
```fortran
! Fortran 2018；module + implicit none
module modern
  use iso_fortran_env, only: real64
  implicit none
contains
  subroutine solve(x)
    real(real64), intent(inout) :: x
    x = x + 1.0d0
  end subroutine solve
end module modern
```
> 预期：FOS-001~012 均不触发（或仅 INFO 0）；`is_fossil=False`（无遗留信号、TODO 密度 0）。
