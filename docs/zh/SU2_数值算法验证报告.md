## 一、项目概况

SU2 是斯坦福大学开发的开源 CFD 求解器框架，支持可压缩/不可压缩流、共轭传热、形状优化等。使用有限体积法，支持隐式/显式时间推进。

| 项目 | 数据 |
|:-----|:------|
| 源码规模 | 1,764 个数值相关文件 |
| 求解器文件 | 805 |
| 语言构成 | C++ 为主 |
| 类型 | CFD 求解器 |

## 四、各维度详细分析

### 4.1 数值稳定性保障（100 分）

| 检测项 | 值 | 说明 |
|:-------|:---|:------|
| total_solver_files | 805 | `CSolver`、`CIntegration` 等求解器类 |
| explicit_scheme_files | 95 | RK4、Runge-Kutta 显式格式 |
| cfl_ratio | **11.8%** | 显式格式占比可控 |
| has_cfl_control | ✅ True | `CFL`、`CFL_ADAPT`、`CFL_RAMP` |
| has_stability_measures | ✅ True | `upwind`、`limiter`、`artificial` |

**评分路径**：`has_cfl_control AND has_stability_measures → 100 分`。

### 4.2 舍入误差与敏感度控制（80 分）

| 检测项 | 值 |
|:-------|:---|
| cancellation_sites | **42** |
| has_kahan_summation | ✅ **True** |
| has_dynamic_tool | ✅ **True**（Valgrind）|

**评分路径**：
```
cancellation(42) > 0  → 扣 20 → 80
has_dynamic_tool      → 不额外扣分
has_kahan             → 不额外扣分
score = 80
```

42 处相消模式主要集中在边界层梯度计算和通量差分中，这与案例集 §3.1（SU2 伴随流相消性损失）的描述一致。
