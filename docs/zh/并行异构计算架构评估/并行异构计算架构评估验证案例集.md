## 一、A 类：可复现开源项目案例（正样本/健康）

> A 类通过 `scripts/fetch_project.py` 或本地样本获取固定 ref；预期结果为**手工语义预期**（正样本应"不应触发"或"低触发"），供阶段 B 对照验证。**缺陷（负例）由 §四 合成承担**（四样本均为健康样本，不作为缺陷阳性）。

### A-1：OpenFOAM — MPI halo 正样本

- **获取**：`D:\OPENSOURCE\OpenFOAM-v2512`（或 `projects.yaml`）；关键锚点 `src/OpenFOAM/meshes/polyMesh/polyPatches/constraint/processor/processorPolyPatch.H`、`.../mapDistributeBase.H`
- **架构分析**：
  - `processorPolyPatch` 用成对 `UOPstream`/`UIPstream` 交换 halo（HPC-005 良好实践）
  - `initInterfaceMatrixUpdate`/`updateInterfaceMatrix` 支持通信/计算重叠（HPC-007 良好实践）
  - `#pragma omp` 仅 2 文件 → **≈纯 MPI**；无 GPU → HPC-001~004 N/A
- **预期结果（v0.8）**：
  - HPC-005 → **低触发/不触发**（成对交换）
  - HPC-007 → **不触发**（可重叠）
  - HPC-001/002/003/004 → **N/A**（无 GPU 信号）
  - HPC-010 → N/A（无 `omp parallel` 内调 MPI）；HPC-011/012 → 低/局部（全仓 2 个 `#pragma omp`，`src` 1 个）

### A-2：deal.II — 负载加权正样本

- **获取**：`D:\OPENSOURCE\dealii`（**本地 checkout，rev 待固定：H3-F2；projects.yaml 暂缺 fetch.ref**）；关键锚点 `include/deal.II/distributed/p4est_wrappers.h`、`source/distributed/tria.cc`（`PartitionWeights`/`get_cell_weights`）
- **架构分析**：`p4est` 分区 + 加权分区支持（HPC-008 良好实践）；MPI + TBB/Taskflow 线程；**Kokkos（`portable_matrix_free`/step-64，GPU-capable；9.7 起取代 CUDAWrappers）**
- **预期结果（v0.8）**：
  - HPC-008 → **低触发**（有 `PartitionWeights`/`get_cell_weights` 加权信号 → 通过）
  - HPC-001~004 → **适用（GPU-capable via Kokkos，能力判定）**，预期**低触发/不触发**（`portable_matrix_free` 单一可移植内核、Kokkos 抽象 launch；GPU 执行需构建 Kokkos CUDA/HIP 后端，默认 CPU 构建走 CPU 后端）。**信号口径**：源码 `source/base/index_set.cc` 的 `KOKKOS_ENABLE_CUDA` 与 `config.h.in`/`FindDEAL_II_KOKKOS.cmake` 的 `DEAL_II_KOKKOS_ENABLE_HIP` 仅表**能力**；`.h.in`/cmake 分支为模板/分支，实际后端以生成 `config.h`/CMakeCache 为准（避免 CPU 构建被恒判 GPU 适用）
  - HPC-010 → **静态 N/A**（HPC-010 静态检测**仅覆盖 `omp parallel` 作用域**；deal.II 以 TBB/Taskflow 线程为主，OpenMP 仅 SIMD（`DEAL_II_OPENMP_SIMD` 9 文件）、无 `omp parallel` 作用域 → 交运行时 MUST/TSan 复核）

### A-3：MFEM — GPU 正样本

- **获取**：`D:\OPENSOURCE\mfem`（**本地 checkout，rev 待固定：H3-F2；projects.yaml 暂缺 fetch.ref**）；关键锚点 `general/device.hpp`、`general/forall.hpp`、`config/config.hpp.in`
- **架构分析**：
  - `Device::Allows`/`Configure` + `#ifdef MFEM_USE_CUDA/HIP`（HPC-002 守卫良好实践）
  - 统一 `MFEM_HOST_DEVICE` 内核（0 `.cu/.hip`）→ 无双实现分歧（HPC-001 正样本）
  - launch 集中 `MFEM_FORALL`（`<<<>>>` 共 8 处：`forall.hpp` 7 + `fem/dfem/util.hpp` 1）→ 无硬编码 launch（HPC-003 正样本）
- **预期结果（v0.8）**：
  - HPC-001/002/003 → **低触发/不触发**
  - HPC-004 → 低触发（统一内核/设备常驻良好）
  - HPC-005/008 → **适用、低触发**（MFEM 有 `MFEM_USE_MPI` + `ParMesh`，halo/分区规则适用）

### A-4：SU2 — 混合并行/线程级正样本

- **获取**：`D:\OPENSOURCE\SU2`（**本地 checkout，rev 待固定：H3-F2；projects.yaml 暂缺 fetch.ref**）；关键锚点 `SU2_CFD/include/solvers/CSolver.hpp`、`SU2_CFD/src/SU2_CFD.cpp`
- **架构分析**：
  - `MPI_Init_thread` 默认 `MPI_THREAD_FUNNELED`、`--thread_multiple` 启 `MULTIPLE`（HPC-010 良好实践）
  - `CSolver.cpp` 每步残差 `Allreduce`（HPC-006 常规用法，非必然缺陷）
  - **无真实 CUDA 代码**（全仓 CUDA 标记仅 `externals/catch2.hpp`）→ HPC-001~004 N/A
- **预期结果（v0.8）**：
  - HPC-010 → **低触发**（显式 FUNNELED/MULTIPLE）
  - HPC-006 → **不触发**（每步残差归约属常规成本，且无"可局部化"迹象；按指南边界不计）
  - HPC-001~004 → N/A（无 GPU）

| 要素 | 内容 |

## 四、合成正负例（12 规则，各 1 正 + 1 负）

> 合成代码片段为**最小示意**（部分为伪代码，已标注），只针对单一规则；引用真实 API 处须与源码一致（阶段 B 校准可编译性）。

### 4.1 HPC-001 双实现一致性

**负例（触发）**：
```cpp
// cpu_kernel.cpp / gpu_kernel 各写一份，归约顺序不同
double sum_cpu(const double* a, int n){ double s=0; for(int i=0;i<n;i++) s+=a[i]; return s; }
// 伪代码（示意）：用并行树归约（顺序不同）→ 与 CPU 结果末位不一致，且无对照测试
```
**正例（不触发）**：
```cpp
// 统一单源内核（如 MFEM_HOST_DEVICE），CPU/GPU 同一份源码
MFEM_HOST_DEVICE double reduce_step(double acc, double v){ return acc + v; }
```

### 4.2 HPC-002 设备可用性守卫

**负例（触发）**：
```cpp
void copy_in(double* d, double* h, int n){ cudaMemcpy(d, h, n*sizeof(double), cudaMemcpyHostToDevice); } // 无守卫
```
**正例（不触发）**：
```cpp
void copy_in(double* d, double* h, int n){
#ifdef USE_CUDA
  if (cudaGetDeviceCount(&cnt)==cudaSuccess && cnt>0) { cudaMemcpy(d,h,n*sizeof(double),cudaMemcpyHostToDevice); return; }
#endif
  for(int i=0;i<n;i++) d[i]=h[i];  // CPU 回退
}
```

### 4.3 HPC-003 launch 配置硬编码

**负例（触发）**：
```cpp
#pragma omp target teams num_teams(1024) thread_limit(256) distribute parallel for
for (int i=0;i<N;i++) b[i]=a[i]*2;   // 魔法数，不随 N/设备变化 → INFO
```
**正例（不触发）**：
```cpp
int B = 256, W = 4;
int T = (N + B*W - 1) / (B*W);
#pragma omp target teams num_teams(T) thread_limit(B*W) distribute parallel for
for (int i=0;i<N;i++) b[i]=a[i]*2;
```

### 4.4 HPC-004 H2D/D2H 冗余搬运

**负例（触发）**：
```cpp
for (int step=0; step<steps; step++){
  cudaMemcpy(d_a, a, n*sizeof(double), cudaMemcpyHostToDevice);   // 循环内反复搬运
  kernel<<<...>>>(d_a);
  cudaMemcpy(a, d_a, n*sizeof(double), cudaMemcpyDeviceToHost);
}
```
**正例（不触发）**：
```cpp
#pragma omp target data map(tofrom:a[0:n])
for (int step=0; step<steps; step++){
  #pragma omp target teams distribute parallel for
  for (int i=0;i<n;i++) a[i]+=f(a[i]);   // 常驻复用，不重复搬运
}
```

### 4.5 HPC-005 halo 交换配对

**负例（触发）**：
```cpp
void exchange_only(MPI_Comm comm, int right, double* buf, int n) {
    MPI_Request req;
    MPI_Isend(buf, n, MPI_DOUBLE, right, 0, comm, &req);
    // 同作用域，函数返回前无 Wait/Test → 触发 HPC-005
}
```
**正例（不触发）**：
```cpp
MPI_Request req[2];
MPI_Isend(sbuf, n, MPI_DOUBLE, right, 0, comm, &req[0]);
MPI_Irecv(rbuf, n, MPI_DOUBLE, left,  0, comm, &req[1]);
MPI_Waitall(2, req, MPI_STATUSES_IGNORE);
```

### 4.6 HPC-006 热循环集合通信

**负例（触发）**：
```cpp
for (int iter=0; iter<maxIter; iter++){          // 时间/迭代循环
  step();
  // 该 global 仅用于每步日志打印、不参与收敛判定 → 可在 rank 本地累加、循环后再归约（可局部化）
  MPI_Allreduce(&local, &global, 1, MPI_DOUBLE, MPI_SUM, comm);  // 高频且可局部化 → 候选
}
```
**正例（不触发）**：
```cpp
for (int iter=0; iter<maxIter; iter++) local += step();   // 局部累加
MPI_Allreduce(&local, &global, 1, MPI_DOUBLE, MPI_SUM, comm);  // 循环外一次
```

### 4.7 HPC-007 通信/计算未重叠

**负例（触发）**：
```cpp
MPI_Send(buf, n, MPI_DOUBLE, right, 0, comm);   // 阻塞发送
compute_interior();                              // 紧接着计算，未重叠 → INFO
```
**正例（不触发）**：
```cpp
MPI_Request req;
MPI_Isend(buf, n, MPI_DOUBLE, right, 0, comm, &req);
compute_interior();                              // 与通信重叠
MPI_Wait(&req, MPI_STATUS_IGNORE);
```

### 4.8 HPC-008 负载划分未加权

**负例（触发）**：
```cpp
// 伪代码（示意）：自适应细化/粗化（非均匀迹象）
void refine_step(Mesh& m){ m.refineLocally(); m.coarsenLocally(); }
// 却用均等分区、无 weights → 候选 HPC-008
// system/decomposeParDict: method simple; numberOfSubdomains 64;   （无 weights）
```
**正例（不触发）**：
```cpp
// 伪代码（示意）：p4est 按权重分区（最小示意）
p4est_gloidx_t* weights = compute_cell_weights(m);   // 单元计算量权重
p4est_partition(p4est, 0, weights);                  // 加权分区
// 或 deal.II：triangulation.repartition(PartitionWeights(...))
```

### 4.9 HPC-009 通信域/拓扑未隔离

**负例（触发）**：
```cpp
void app_run(){ int n; MPI_Comm_size(MPI_COMM_WORLD, &n); }   // 应用侧用 WORLD
void lib_init(){ /* 库内部也直接用 MPI_COMM_WORLD 做集合通信 */ MPI_Barrier(MPI_COMM_WORLD); }  // 两域共用 WORLD 未隔离 → INFO
```
**正例（不触发）**：
```cpp
MPI_Comm lib_comm;
MPI_Comm_split(MPI_COMM_WORLD, lib_color, rank, &lib_comm);   // 隔离通信域
MPI_Barrier(lib_comm);
```

### 4.10 HPC-010 非线程安全 MPI

**负例（触发）**：
```cpp
// MPI_Init_thread(..., MPI_THREAD_FUNNELED, ...)
#pragma omp parallel
{ MPI_Allreduce(&local,&global,1,MPI_DOUBLE,MPI_SUM,comm); }   // 非主线程调 MPI → WARNING/ERROR
```
**正例（不触发）**：
```cpp
#pragma omp parallel
{
  #pragma omp for
  for(int i=0;i<n;i++) local+=work(i);
  #pragma omp master
  { MPI_Allreduce(&local,&global,1,MPI_DOUBLE,MPI_SUM,comm); }  // 仅主线程
}
```

### 4.11 HPC-011 OpenMP 共享变量误用

**负例（触发）**：
```cpp
double sum=0;
#pragma omp parallel for
for(int i=0;i<n;i++) sum += a[i];    // 共享变量无 reduction → 竞态（候选）
```
**正例（不触发）**：
```cpp
double sum=0;
#pragma omp parallel for reduction(+:sum)
for(int i=0;i<n;i++) sum += a[i];
```

### 4.12 HPC-012 并行域嵌套违规

**负例（触发）**：
```cpp
#pragma omp parallel
{ #pragma omp parallel
  for(int i=0;i<n;i++) work(i); }    // 并行域嵌套 → WARNING
```
**正例（不触发）**：
```cpp
#pragma omp parallel for
for(int i=0;i<n;i++) work(i);        // 单并行域；或 parallel + task
```
