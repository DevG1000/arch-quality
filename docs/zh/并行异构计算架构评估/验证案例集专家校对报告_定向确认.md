## 四、补充：deal.II GPU 事实更正（2026-10-21）

**发现**：案例集原写 A-2 deal.II "无 GPU / HPC-001~004 N/A"，经本地源码核验**不成立**。

**证据（deal.II 9.8.0-pre）**：
- `cmake/configure/configure_30_kokkos.cmake:17` `set(DEAL_II_WITH_KOKKOS ON # Always true)`；"Kokkos is always required"
- `include/deal.II/base/config.h.in:102` `#cmakedefine DEAL_II_WITH_KOKKOS`
- `examples/step-64/doc/tooltip:1` "Portable Matrix-free methods on **devices** using **Kokkos** and MPI"；`step-64.cc:360` `Kokkos::parallel_for`
- `include/deal.II/matrix_free/portable_matrix_free.h:39-40` `Kokkos_Core.hpp`；`:85` `Kokkos::View<..., MemorySpace::Default::kokkos_space>`
- `doc/news/9.6.0-vs-9.7.0.h:259-260`"Removed: All support for CUDAWrappers ... **GPU support is provided through Kokkos**."
- 自身代码 77 文件引用 Kokkos（排除 bundled），内置 `bundled/kokkos-4.5.01`

**结论**：deal.II **GPU-capable（经 Kokkos）**；GPU 执行需构建 Kokkos CUDA/HIP 后端（默认 CPU 构建走 CPU 后端）。

**已落实修正**：
| 文档 | 修正 | 版本 |
|:--|:--|:--|
| 设计依据 | 性能可移植范式补 deal.II（Kokkos）；正样本/附录 A 补 Kokkos 锚点与"HPC-001/003 正样本" | v0.3→**0.4** |
| 指南 | 适用范围/§7.4/§八 GPU 信号补 `Kokkos::`/`KOKKOS_ENABLE_*`/`DEAL_II_WITH_KOKKOS` | v0.7→**0.8** |
| 案例集 | A-2 由"无 GPU/N/A"改为"**GPU-capable via Kokkos**，HPC-001~004 适用、预期低触发"；绑定升 v0.8 | v0.2→**0.3** |

**教训**：案例主张必须源码核验——SU2 是"说有 GPU 实际无"，deal.II 是"说无 GPU 实际有"，方向相反、教训相同。
