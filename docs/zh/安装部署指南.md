# 架构质量评估智能体 — 安装部署指南

## 前提条件

- Python ≥ 3.10
- pip（通常随 Python 安装）
- Git（用于克隆仓库）
- OpenCode（如需智能体集成）

## 方式一：从 GitHub 安装（推荐）

### 1. 克隆仓库

```bash
git clone https://github.com/<your-org>/arch-quality.git
cd arch-quality
```

### 2. 安装包（开发模式）

```bash
pip install -e .
```

这会：
- 安装 `arch_quality` Python 包到当前 Python 环境
- 注册 3 个命令行入口点：`arch-quality`、`arch-quality-standard`、`arch-quality-multilang`
- 以 editable 模式安装，修改源码后无需重新安装

### 3. 将 Scripts 目录加入 PATH（Windows）

安装后脚本位于 `%APPDATA%\Python\Python3X\Scripts\`，若该路径不在 PATH 中：

```powershell
# 查看脚本实际安装路径
pip show -f arch-quality | findstr Scripts

# 方法 A：临时加入当前会话
$env:PATH = "C:\Users\<用户名>\AppData\Roaming\Python\Python3XX\Scripts;" + $env:PATH

# 方法 B：永久加入（推荐）
# 系统设置 → 环境变量 → 用户变量 → Path → 新增上述路径
```

Linux/macOS 通常无需额外操作，`~/.local/bin` 已默认在 PATH 中。

### 4. 验证安装

```bash
# 方式 1：直接命令
arch-quality --help

# 方式 2：Python 模块方式（无需 PATH）
python -m arch_quality --help
```

### 5. 运行评估

```bash
# 评估当前目录
arch-quality
# 或
python -m arch_quality

# 评估指定项目
arch-quality D:\path\to\project

# 指定报告模式
arch-quality --report-mode central
arch-quality --report-mode local D:\path\to\project

# 仅输出 JSON
arch-quality --json D:\path\to\project

# 仅输出 Markdown
arch-quality --md D:\path\to\project
```

## 方式二：配置 OpenCode 智能体集成

OpenCode 智能体需要**两步注册**：复制智能体定义文件 + 配置 `opencode.jsonc`。

### 1. 确认 arch-quality 命令可用

```bash
arch-quality --help
# 或使用 python -m 方式
python -m arch_quality --help
```

### 2. 复制智能体定义

将项目中的 `integrations/opencode/architecture-quality.md` 复制到 OpenCode 全局智能体目录：

**Windows:**
```powershell
copy integrations\opencode\architecture-quality.md %USERPROFILE%\.config\opencode\agents\architecture-quality.md
```

**Linux/macOS:**
```bash
cp integrations/opencode/architecture-quality.md ~/.config/opencode/agents/architecture-quality.md
```

### 3. 配置 opencode.jsonc

编辑 OpenCode 全局配置文件（`~/.config/opencode/opencode.jsonc`），注册智能体并授权：

> **注意**：如果文件已包含其他配置，请将 `agent.architecture-quality` 部分合并到现有配置中，不要覆盖其他设置。

**Windows** (`%USERPROFILE%\.config\opencode\opencode.jsonc`):
```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "agent": {
    "architecture-quality": {
      "description": "架构质量评估智能体 — 系统性分析、评估和改进软件系统架构质量，支持多语言混合依赖评估",
      "prompt_file": "C:\\Users\\<你的用户名>\\.config\\opencode\\agents\\architecture-quality.md",
      "mode": "subagent",
      "permission": {
        "read": "allow",
        "bash": {
          "*": "ask",
          "arch-quality*": "allow",
          "arch-quality *": "allow",
          "python -m arch_quality*": "allow"
        },
        "edit": "deny",
        "task": "allow",
        "skill": "allow"
      }
    }
  }
}
```

**Linux/macOS** (`~/.config/opencode/opencode.jsonc`):
```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "agent": {
    "architecture-quality": {
      "description": "架构质量评估智能体 — 系统性分析、评估和改进软件系统架构质量，支持多语言混合依赖评估",
      "prompt_file": "~/.config/opencode/agents/architecture-quality.md",
      "mode": "subagent",
      "permission": {
        "read": "allow",
        "bash": {
          "*": "ask",
          "arch-quality*": "allow",
          "arch-quality *": "allow",
          "python -m arch_quality*": "allow"
        },
        "edit": "deny",
        "task": "allow",
        "skill": "allow"
      }
    }
  }
}
```

**权限说明**：
- `"arch-quality*"` — 匹配 `arch-quality` 不带参数
- `"arch-quality *"` — 匹配 `arch-quality` 后跟参数（如 `arch-quality D:\project`）
- `"python -m arch_quality*"` — 匹配 `python -m arch_quality` 及其参数
- `"*": "ask"` — 其他命令需用户确认
- `"edit": "deny"` — 智能体不可修改项目代码

### 4. 重启 OpenCode

修改 `opencode.jsonc` 后**必须重启 OpenCode** 才能生效。运行中的会话使用的是启动时加载的配置。

### 5. 验证智能体

在任意项目目录中，通过 OpenCode 调用架构评估智能体即可自动运行评估。

## 方式三：从本地目录安装（离线）

如果目标机器无法访问 GitHub，可将整个 `arch-quality` 目录拷贝到目标机器：

```bash
# 在目标机器上
cd arch-quality
pip install -e .
```

## 子命令

安装后提供 3 个命令行工具：

| 命令 | 入口函数 | 用途 |
|------|---------|------|
| `arch-quality` | `arch_quality.arch_report:main` | 综合评估（JSON + Markdown） |
| `arch-quality-standard` | `arch_quality.arch_metrics_standard:main` | 标准 4 维指标 |
| `arch-quality-multilang` | `arch_quality.arch_metrics_multilang:main` | 多语言 6 维 + 12 MLR |

## 报告存储

| 模式 | 路径 | 说明 |
|------|------|------|
| `local` | `<项目根>/.opencode/arch-reports/YYYY-MM-DD/` | 单项目本地保存 |
| `central`（默认） | `~/.config/opencode/arch-reports/<project-slug>/YYYY-MM-DD/` | 多项目集中管理 |

## 卸载

```bash
pip uninstall arch-quality
```

如需同时移除 OpenCode 智能体定义：

**Windows:**
```powershell
del %USERPROFILE%\.config\opencode\agents\architecture-quality.md
```

**Linux/macOS:**
```bash
rm ~/.config/opencode/agents/architecture-quality.md
```

## 故障排除

### Windows 中文乱码

确保终端使用 UTF-8 编码：
```powershell
chcp 65001
$env:PYTHONIOENCODING = "utf-8"
$env:PYTHONUTF8 = "1"
```

或使用 `scripts/arch-quality.bat` 启动器，它会自动设置这些环境变量。

### `arch-quality` 命令找不到

1. 确认 `pip install -e .` 成功执行
2. 确认 Scripts 目录在 PATH 中（见上方第 3 步）
3. 或使用 `python -m arch_quality` 替代

### 权重文件找不到

确保 `skills/` 目录在包安装路径下：
```bash
pip show -f arch-quality | findstr skills
```

如果权重文件缺失，检查 `pyproject.toml` 中的 `[tool.setuptools.package-data]` 配置。
