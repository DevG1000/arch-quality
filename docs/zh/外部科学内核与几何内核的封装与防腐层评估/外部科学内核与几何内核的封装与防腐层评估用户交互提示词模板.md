# 外部科学内核与几何内核的封装与防腐层评估 — 用户交互提示词模板

> 文档编号：ACL-C3-用户提示词
> 说明：面向用户在 OpenCode 中使用的提示词模板，用于调用 `architecture-quality` 智能体执行外部内核防腐层评估。
> 关联文档：《外部科学内核与几何内核的封装与防腐层评估指南（1.3版）》

---

## 1. 基础评估

```
请对 [项目路径] 执行外部科学内核与几何内核的封装与防腐层评估，
汇报 4 维得分（外部内核访问防腐/Wrapper 覆盖与演进守卫/数据交换防腐/保真度与标准一致性）和 ACL 违规清单。
```

**示例**：
```
请对 D:/opensource/OCCT 执行外部内核防腐层评估，
汇报 4 维得分和 ACL 违规清单。
```

## 2. 单维度分析

```
请分析 [项目路径] 的外部内核访问防腐（external_access）：
业务层是否绕过 wrapper 直连内核 API？wrapper 公开签名是否泄漏内核类型（TopoDS_/Handle_）？
内核调用失败（IsDone/异常）是否被封装层捕获？
```

## 3. ACL 规则排查

```
请检查 ACL-00X（规则名称）在 [项目路径] 中的具体情况，
说明违规的影响范围和建议修复方式。
```

**示例**：
```
请检查 ACL-007（STEP/IGES/IFC 读写防腐）在 D:/opensource/SALOME 中的具体情况，
说明哪些文件在 import/export 模块外直接使用 STEPControl_*，以及如何收敛到集中模块。
```

## 4. 改进建议

```
请基于最近一次评估结果，给出 [项目路径] 外部内核防腐层改进建议，
按 P0/P1/P2 优先级分级，并预估每项改进的得分提升空间。
```

## 5. 历史对比

```
请将 [项目路径] 的当前防腐层得分与历史基线对比，
报告得分偏移和 ACL 违规变化，判断是否出现退化。
```

## 6. 专项审查

```
请审查 [项目路径] 是否满足以下外部内核防腐专项要求：
- wrapper 目录是否收敛全部内核调用（无业务层直连 TopoDS_/BRep*）
- STEP/IGES/IFC 读写是否集中在 import/export 模块
- reader/writer 调用点是否检查 IFSelect_ReturnStatus
- 是否存在 round-trip 往返保真度测试
- 是否声明外部标准版本（AP203/214/242）守卫
```

## 7. 内核升级影响面评估

```
请评估 [项目路径] 升级其外部内核（OCCT 等）时的影响面：
基于 ACL-001/002/003 违规情况，估算被业务层直连的内核 API 数量，
并建议 wrapper 收敛与版本守卫（#if OCC_VERSION）的改造范围。
```

*本模板供用户在与 `architecture-quality` 智能体交互时使用，与指南 §七 实施建议对齐。*
