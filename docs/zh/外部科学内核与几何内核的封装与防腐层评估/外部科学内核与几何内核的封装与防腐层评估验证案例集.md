## 一、A 类：可复现开源项目案例

> A 类案例通过 `scripts/fetch_project.py` 获取固定 ref，可复现。预期结果为**手工语义预期**，供 WP-4 B3.5 对照验证（防误报/漏报）。

### A-1：OCCT（Open CASCADE Technology）— 数据交换防腐正样本

- **获取方式**：`python scripts/fetch_project.py occt --dest <dir>`（tag V8.0.1，commit `b8f597c6`）
- **架构分析**：
  - `src/DataExchange/`（`TKDESTEP`/`TKDECIGES`/`TKDEIFC`）**集中承载** STEP/IGES/IFC 读写与单位换算（ACL-006/007 良好实践参照）
  - `STEPControl_Writer`/`STEPControl_Reader` 带标准版本/单位参数，`IFSelect_ReturnStatus` 错误处理集中（ACL-007/011）
  - 自带测试套件（`TKDETEST`）含 STEP 往返保真/读写一致性验证（ACL-006 预期命中，B3.5 实测确认）
- **预期结果（阳性，B3.5 实测校准）**：
  - ACL-001（直连内核 API）→ 低违规范（OCCT 自身即内核，DataExchange 使用为正常内部访问，需结合内核目录排除豁免）
  - ACL-007（数据交换防腐）→ **低违规范**（读写集中在 DataExchange，作清晰正例）
  - ACL-006（往返保真度测试）→ **存在（加分）**（TKDETEST STEP 往返测试，B3.5 实测确认）
  - ACL-010（标准版本守卫）→ 低违规范（STEPControl_Writer 显式 AP 版本参数）

> **A-1 定位说明**：OCCT 既是维度④ 内核样本又是维度⑧ 数据交换防腐样本。ACL 侧关注其 **DataExchange 模块化形态**（读写集中、错误处理、round-trip），不评其内核自身正确性。

### A-2：SALOME GEOM — 内核封装防腐正样本

- **获取方式**：`python scripts/fetch_project.py salome-geom --dest <dir>`（commit `3f85d2e2`）
- **架构分析**：
  - `GEOMImpl` 封装 OCCT 操作，业务层经 `GEOM_Gen`/`GEOM_Object` 间接访问（ACL-001 低违规范，ACL-005 封装良好）
  - `STEPPlugin`/`IGESPlugin`/`BREPPlugin` 数据交换插件集中（ACL-007 良好实践）
  - `GEOM_IBaseObject` 等接口隔离内部 `TopoDS_Shape`（ACL-004 类型泄漏低）
- **预期结果**：
  - ACL-001（直连内核）→ 低违规范（GEOMImpl 无外层泄漏）
  - ACL-004（类型泄漏）→ 低违规范（接口层用 GEOM_* 自有类型）
  - ACL-005（错误处理封装）→ 低违规范（GEOMImpl 集中处理内核失败）
  - ACL-002（wrapper 覆盖度）→ 中违规范（部分冷门内核 API 仍直连，作校准点）

### A-3：FreeCAD（兜底）— 内核封装正样本

- **获取方式**：已在 `projects.yaml`（`fetch.repo: FreeCAD`）
- **预期结果**：ACL-001（OCCT 封装形态）低-中违规范、ACL-004（类型泄漏）中违规范（Part/PartDesign 模块边界）

### A-4：BRL-CAD（兜底）— 实体建模样本

- **获取方式**：已在 `projects.yaml`
- **预期结果**：外部内核接入形态触发情况待实测（BRL-CAD 自研内核，ACL 触发场景少，作 CKD 校验）

> **兜底说明**：若 OCCT/SALOME 获取失败（网络/授权），ACL 回归用 FreeCAD/BRL-CAD 兜底（H2 决策 4）。

## 三、C 类：Validation 案例（6 要素）

### C-1：CAD 平台内核升级影响面控制（首期）

| 要素 | 内容 |
|:-----|:-----|
| **前情背景** | 某 CAD 平台基于 OCCT 做几何操作，业务模块直接调用 `BRepAlgoAPI_Fuse` 等 API，准备从 OCCT 7.6 升级到 8.0 |
| **关键数据** | 指南输出 ACL-001（直连内核 API ERROR）+ ACL-004（类型泄漏 WARNING）+ ACL-002（覆盖度 INFO）告警，维度⑧ 综合分 48 |
| **用户行为** | 架构师针对 **ERROR 级 ACL-001** 整改：建立 wrapper 目录收敛全部内核调用；对 **WARNING 级 ACL-004** 调整 wrapper 公开接口隔离 `TopoDS_Shape`；补充 `#if OCC_VERSION` 版本守卫（ACL-003）|
| **工具响应** | 复评后 ACL-001 清零、ACL-004 违规范下降、ACL-003 命中，综合分 48 → 78；升级影响面估算缩小到 wrapper 目录 |
| **业务价值** | 升级周期从"全仓改代码"收敛为"改 wrapper 与守卫"，升级回归风险可控 |
| **推广复制** | 形成"内核升级前先评估防腐层"实践清单，推广到全部外部依赖升级环节 |

### C-2：STEP 导出一致性修复（二期）

| 要素 | 内容 |
|:-----|:-----|
| **前情背景** | 某 CAE 平台 STEP 导出结果跨版本不一致，现场交付数据损坏 |
| **关键数据** | 指南输出 ACL-007（读写散落 ERROR）+ ACL-008（单位换算魔法因子 INFO）+ ACL-006（round-trip 缺失 INFO），综合分 55 |
| **用户行为** | 集中 STEP 读写到 import/export 模块；统一 `unit::convert()`；补 round-trip 测试 |
| **工具响应** | 复评后 ACL-007 清零、ACL-006 命中（加分）、ACL-008 违规范下降，综合分 55 → 74 |
| **业务价值** | 导出结果跨版本一致，现场交付损坏消除 |
| **推广复制** | 数据交换防腐检查清单推广到 IGES/IFC 路径 |

## 四、合成正负例

> 每个 🟢 规则（ACL-001/006/007/012）含 1 正例 + 1 负例；每个 🟡 规则（ACL-002/003/004/005/008/009/010/011）含 ≥1 INFO/正反例。合成代码片段 50-300 行。

### 4.1 ACL-001 直连内核 API

**负例（触发 ACL-001）**：
```cpp
// business/direct_fuse.cpp  ← wrapper 目录白名单外
#include <BRepAlgoAPI_Fuse.hxx>
TopoDS_Shape merge(MatShape& a, MatShape& b) {
    BRepAlgoAPI_Fuse op(a.inner(), b.inner());  // 直接调用内核 API，未经 wrapper → ACL-001 ERROR
    return op.Shape();
}
```

**正例（不触发）**：
```cpp
// wrapper/cad_ops.cpp  ← wrapper 目录白名单内
#include <BRepAlgoAPI_Fuse.hxx>
namespace wc { MatShape merge(const MatShape& a, const MatShape& b) {
    BRepAlgoAPI_Fuse op(a.inner(), b.inner());   // 内核调用收敛在 wrapper 内 → 合法
    if (!op.IsDone()) throw std::runtime_error("fuse failed");
    return MatShape::wrap(op.Shape());
}}
// business/merge.cpp  ← 只依赖 wrapper 接口
#include "wrapper/cad_ops.hh"
MatShape m = wc::merge(a, b);                    // 业务层经 wrapper → 不触发
```

> **覆盖说明**：正例验证"wrapper 内的内核调用不误报"，负例验证"白名单外直连触发 ERROR"。

### 4.2 ACL-002 核心 API wrapper 覆盖度（🟡 INFO）

**负例（触发 ACL-002）**：
```cpp
// wrapper/cad_ops.hh —— 核心内核类清单（BRepAlgoAPI_Fuse/BRepAlgoAPI_Cut/BRepFilletAPI_MakeFillet）
// 仓库仅 wrapper 了 Fuse，核心类 MakeFillet 无 wrapper 声明，业务层被迫直连
#include "wrapper/cad_ops.hh"
#include <BRepFilletAPI_MakeFillet.hxx>   // 冷门但核心 API 无 wrapper → ACL-002 INFO
TopoDS_Shape fillet(const TopoDS_Shape& s) { BRepFilletAPI_MakeFillet f(s); return f.Shape(); }
```

**正例（不触发）**：
```cpp
// wrapper/cad_ops.hh —— 核心内核类清单全覆盖
class MakeFillet { public: MakeFillet(const MatShape&); MatShape Result(); };  // 声明存在
// 业务层经 wrapper::MakeFillet 使用，无直连
```

### 4.3 ACL-003 内核版本守卫（🟡 INFO）

**负例（触发 ACL-003）**：
```cpp
// wrapper/cad_ops.cpp
#include <BRepAlgoAPI_Fuse.hxx>
// 内核已跨 7.6→8.0 演进，wrapper 内无任何 #if OCC_VERSION 分支 → ACL-003 INFO
MatShape merge(const MatShape& a, const MatShape& b) { BRepAlgoAPI_Fuse op(...); return ...; }
```

**正例（不触发）**：
```cpp
#if OCC_VERSION >= 70800
    // 8.0 之后的新 API
#else
    // 7.6 兼容分支
#endif
// 守卫密度覆盖全部版本差异 → ACL-003 命中
```

### 4.4 ACL-004 内核类型泄漏

**负例（触发 ACL-004）**：
```cpp
// wrapper/cad_ops.hh（public 接口）
#include <TopoDS_Shape.hxx>
class CadEngine {
public:
    TopoDS_Shape do_fuse(const TopoDS_Shape& a, const TopoDS_Shape& b);  // 外部内核类型泄漏进 public 签名 → ACL-004 WARNING
    Handle(Geom_Surface) make_plane();                                   // 同上
};
```

**正例（不触发）**：
```cpp
// wrapper/cad_ops.hh
#include "MatShape.hh"      // 自有值类型
class CadEngine {
public:
    MatShape do_fuse(const MatShape& a, const MatShape& b);   // 公有接口用自有类型 → 不触发
    // TopoDS_Shape 仅出现在 wrapper 内部 .cpp 实现（合法）
};
```

### 4.5 ACL-005 错误处理封装（异常型/状态码型）

**负例（触发 ACL-005）**：
```cpp
// wrapper/cad_ops.cpp —— 状态码型内核失败未检查
#include <BRepAlgoAPI_Fuse.hxx>
MatShape merge(MatShape& a, MatShape& b) {
    BRepAlgoAPI_Fuse op(a.inner(), b.inner());
    return MatShape::wrap(op.Shape());   // 未检查 op.IsDone() → ACL-005 WARNING（状态码型）
}
```

**正例（不触发）**：
```cpp
// wrapper/cad_ops.cpp —— 异常型内核 try/catch + 状态码型检查
#include <BRepAlgoAPI_Fuse.hxx>
MatShape merge(MatShape& a, MatShape& b) {
    try {
        BRepAlgoAPI_Fuse op(a.inner(), b.inner());
        if (!op.IsDone()) throw std::runtime_error("fuse failed");  // 状态码检查
        return MatShape::wrap(op.Shape());
    } catch (const std::exception& e) { throw; }  // 异常型内核心 try/catch
}
```

### 4.6 ACL-006 数据交换往返保真度测试存在性（加分项）

**缺失（INFO 提示）**：
```cpp
// importexport/step_io.cpp —— 有读写，但无 round-trip 测试
void export_step(const char* path) { STEPControl_Writer w; w.Transfer(shape_); w.Write(path); }
// 仓库无 round_trip 测试符号 → ACL-006 缺失提示（INFO）
```

**存在（加分）**：
```cpp
// importexport/test_step_stability.cpp
TEST(StepIO, RoundTrip) {
    STEPControl_Writer w; w.Transfer(shape_); w.Write(tmp);
    STEPControl_Reader r; r.ReadFile(tmp); r.TransferRoots();
    ASSERT_TRUE(r.IsDone());
    ASSERT_GEOM_EQUALS(r.OneShape(), shape_);   // 写出→读回→一致性比较 → ACL-006 加分
}
```

### 4.7 ACL-007 STEP/IGES/IFC 读写防腐

**负例（触发 ACL-007）**：
```cpp
// business/model_export.cpp  ← import/export 模块白名单外
#include <STEPControl_Writer.hxx>
#include <STEPControl_Reader.hxx>
void export_part(Part& p) {
    STEPControl_Writer w; w.Transfer(p.shape()); w.Write("part.stp");  // 格式读写散落业务模块 → ACL-007 ERROR
}
```

**正例（不触发）**：
```cpp
// importexport/step_io.cpp  ← import/export 模块白名单内
#include <STEPControl_Writer.hxx>
namespace io {
void export_step(const Part& p) { STEPControl_Writer w; w.Transfer(p.shape()); w.Write("part.stp"); }
}  // 读写集中在集中模块 → 合法
// business 只调用 io::export_step(p)
```

> **覆盖说明**：ACL-007 与 4.7 正例验证"集中读写不误报"，负例验证"散落触发 ERROR"；与 ACL-012 区分（007 管位置形态，012 管引用密度）。

### 4.8 ACL-008 单位换算魔法因子（🟡 INFO）

**负例（触发 ACL-008）**：
```cpp
// importexport/step_io.cpp —— 数据交换上下文
double export_len(const double v_inch) {

```

**正例（不触发）**：
```cpp
// importexport/step_io.cpp
#include "unit.hh"
double export_len(const double v) { return unit::convert(v, unit::INCH, unit::MM); }  // 集中工具函数
```

### 4.11 ACL-011 导入导出错误处理

**负例（触发 ACL-011）**：
```cpp
// importexport/step_io.cpp
#include <STEPControl_Reader.hxx>
void import_step(const char* path) {
    STEPControl_Reader r; r.ReadFile(path);        // 未检查 IFSelect_ReturnStatus → ACL-011 WARNING

}
```

**正例（不触发）**：
```cpp
#include <STEPControl_Reader.hxx>
void import_step(const char* path) {
    STEPControl_Reader r;
    if (r.ReadFile(path) != IFSelect_RetDone)       // 检查错误状态
        throw std::runtime_error("STEP read failed");
    if (r.TransferRoots() != IFSelect_RetDone) throw std::runtime_error("transfer failed");
    use(r.OneShape());
}
```
