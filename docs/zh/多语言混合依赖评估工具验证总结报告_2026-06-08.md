## 五、技术实现细节

### 5.1 Fortran模块映射（3层解析）

```
use ModuleName
  ├── 1. _fortran_module_map: module XXX → file（排除 module procedure / end module）
  ├── 2. _fortran_subroutine_map: subroutine/function → file
  └── 3. Filename fallback: basename matching
```

ElmerFEM: 107个module声明, 68%文件名匹配, 31%不匹配（`module FetiSolve` in `Feti.F90`等），全部通过模块映射正确解析。

### 5.2 回调深度检测（4路径 + 回退机制）

```
Path 1: cross_edges BFS（依赖图跨语言边）
Path 2: Python回调注册模式 + PyImport_ImportModule增强
    ├── _py_imports_cpp(): import X → X.cpp文件名匹配
    └── _resolve_pyimport_module(): 模块名 → Python文件解析
Path 3: pybind11回调（无GIL释放）
    └── 回退: 无cross_predecessors时用import直连
Path 4: C++ PyImport_ImportModule("module") 动态回调
    └── 回退: 无cross_predecessors时用import直连
```

**关键修复**: 当`self.graph.cross_edges`为空时，Paths 2-4通过`_py_imports_cpp()`和`_resolve_pyimport_module()`直接匹配Python import到C++文件名，无需预建跨语言边。

### 5.3 构建目录支持（`--build-dir`）

```
FileIndex.__init__(root, build_dir="") → _scan_build_dir()
  ├── _wrap.cxx / _wrap.cpp: SWIG生成C++包装
  ├── .i / .swg: SWIG接口定义
  ├── .pyi: Python类型存根
  └── 头文件: 额外C/C++头
```

### 5.4 INFO严重级别

```
MLR结果 severity 字段:
  HIGH   → 影响评分的计算（扣分最重）
  MEDIUM → 影响评分的计算（扣分中等）
  LOW    → 影响评分的计算（扣分轻微）
  INFO   → 不影响评分（纯信息提示）
```

### 5.5 `import X` → C++ basename匹配机制

当Python文件写`import FemSolver`时，工具通过basename对比判断是否指向项目内的C++文件：

```python
_py_imports_cpp():  import X → os.path.splitext(basename(cpp_path))[0] == X
_resolve_pyimport_module(): PyImport_ImportModule("module.name") → module/name.py, name.py
```

**局限**: 仅匹配项目内源码文件，不支持`pip install`安装到site-packages的第三方包路径。项目内C++文件与第三方Python包同名时可能误匹配（实际项目中极少发生）。
