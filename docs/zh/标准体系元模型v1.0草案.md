## 一、概述

本元模型定义 arch-quality 评估体系的**结构化事实源**，统一描述五个引擎的维度、规则、权重、豁免与验证资产，消除散落文档/代码中的重复口径。

**五元素**：维度（Dimension）/ 规则（Rule）/ 权重（Weight）/ 豁免（Waiver）/ 验证资产（Validation Asset）

---

## 二、五元素定义

### 2.1 维度（Dimension）

| 字段 | 类型 | 必填 | 说明 |
|:-----|:----:|:----:|:-----|
| id | string | ✅ | 维度唯一标识（如 dim.structural）|
| name | string | ✅ | 维度名称（中文）|
| engine | string | ✅ | 归属引擎（standard/multilang/template/numerical/solver_physics）|
| weight | number | ✅ | 权重（0~1，激活子集内归一化）|
| description | string | ✅ | 维度定义 |
| sub_dimensions | array | 否 | 子维度列表 |

### 2.2 规则（Rule）

| 字段 | 类型 | 必填 | 说明 |
|:-----|:----:|:----:|:-----|
| id | string | ✅ | 规则 ID（如 TPL-002，[A-Z]{3}-\\d{3}）|
| name | string | ✅ | 规则名称 |
| engine | string | ✅ | 归属引擎 |
| dimension | string | ✅ | 归属维度 id |
| severity | enum | ✅ | HIGH/MEDIUM/LOW |
| output_level | enum | ✅ | ERROR/WARNING/INFO（与 severity 解耦）|
| waivable | bool | ✅ | 是否可豁免 |
| waived_output_level | enum | 否 | 豁免后输出级别 |
| description | string | ✅ | 规则描述/代码坏味道 |

### 2.3 权重（Weight）

| 字段 | 类型 | 必填 | 说明 |
|:-----|:----:|:----:|:-----|
| dimension_id | string | ✅ | 维度 id |
| weight | number | ✅ | 权重值（0~1）|
| scope | enum | ✅ | global（全局固定）/ project（项目激活子集内归一化）|
| source | string | ✅ | 事实源（schema/元模型文件）|

**归一化公理**：任一项目激活的维度权重之和 = 1（激活子集全局归一化，见 WP-7.3 方案）。

### 2.4 豁免（Waiver）

| 字段 | 类型 | 必填 | 说明 |
|:-----|:----:|:----:|:-----|
| annotation | string | ✅ | 注解名（@xxx）|
| rule_id | string | ✅ | 适用规则 ID |
| required_fields | array | ✅ | 必填字段（存在则必填）|
| effect | enum | ✅ | downgrade（降级 INFO）/ skip（跳过）|

### 2.5 验证资产（Validation Asset）

| 字段 | 类型 | 必填 | 说明 |
|:-----|:----:|:----:|:-----|
| id | string | ✅ | 资产唯一标识 |
| rule_id | string | ✅ | 关联规则 ID |
| kind | enum | ✅ | synthetic（合成）/ real（真实）/ case（案例库）|
| path | string | ✅ | 资产位置（验证案例集/测试/快照）|
| expectation | string | ✅ | 预期结果（阳性/阴性）|

## 四、术语表（对齐 ISO 24765 / IEEE 1012）

| 术语 | 定义 | 来源 |
|:-----|:-----|:-----|
| 验证（Verification）| 确定产品是否满足需求的过程 | ISO 24765 |
| 确认（Validation）| 确定产品是否满足预期用途的过程 | ISO 24765 |
| 规则（Rule）| 可机检的架构反模式/质量缺陷判定条件 | 本元模型 |
| 豁免（Waiver）| 对特定规则触发的人工/注解许可 | 本元模型 |
| 观察阶（Observed Order）| MMS 验证实测收敛阶 | IEEE 1012 |
| 技术债务（Technical Debt）| 为短期收益付出的长期维护成本 | 本元模型 |
