# 软件架构质量评估技能

本技能提供通用软件架构质量评估的领域知识，包括 4 大分类和子维度的定义及权重。

## 权重分配

| 维度 | 权重 |
|------|------|
| 结构质量 | 30% |
| 设计质量 | 25% |
| 文档质量 | 20% |
| 演进质量 | 25% |

### 结构质量子维度

| 子维度 | 权重 |
|--------|------|
| 模块化 | 20% |
| 耦合度 | 20% |
| 内聚度 | 20% |
| 复杂度 | 20% |
| 可测试性 | 20% |

### 设计质量子维度

| 子维度 | 权重 |
|--------|------|
| SOLID原则 | 40% |
| 设计模式 | 25% |
| 架构风格 | 20% |
| 反模式 | 15% |

### 文档质量子维度

| 子维度 | 权重 |
|--------|------|
| README完整性 | 25% |
| CHANGELOG完整性 | 15% |
| ADR覆盖率 | 20% |
| 代码注释密度 | 15% |
| JSDoc覆盖率 | 15% |
| 架构文档完整性 | 10% |

### 演进质量子维度

| 子维度 | 权重 |
|--------|------|
| 历史可追溯性 | 16% |
| 技术债务趋势 | 20% |
| 依赖过时程度 | 16% |
| 废弃代码比例 | 12% |
| 增量质量 | 16% |
| 问题扣分 | 20% |

## 评分算法概要

### 结构质量

```
结构质量综合分 = 模块化×20% + 耦合度×20% + 内聚度×20% + 复杂度×20% + 可测试性×20%
```

### 设计质量

```
设计质量综合分 = SOLID×40% + 设计模式×25% + 架构风格×20% + 反模式×15%
```

### 文档质量

```
文档质量综合分 = README×25% + CHANGELOG×15% + ADR×20% + 注释×15% + JSDoc×15% + 架构文档×10%
```

### 演进质量

```
演进质量综合分 = 历史追溯×16% + 债务趋势×20% + 依赖过时×16% + 废弃代码×12% + 增量质量×16% + 问题扣分×20%
```

## 总体评分

```
总分 = 结构质量×30% + 设计质量×25% + 文档质量×20% + 演进质量×25%
```

详细算法说明见 `SOFTWARE_ARCHITECTURE_QUALITY_GUIDE.md`。
